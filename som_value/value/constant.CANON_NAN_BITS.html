Canonical NaN representation (minimum bitfield to represent NaN).

Since we are hijacking most bits in NaN values, all legitimate NaN will need to be “canonicalized” to this representation, which will be the only actual NaN value.

This isn’t that bad since SOM doesn’t have many bit fiddling facilities anyway, so it is unlikely one would need to inspect bits in NaN values.

An NaN is indicated by:

  • sign bit is 0
  • exponent bits are all 1
  • first mantissa bit is 1
